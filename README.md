# TrendVideo AI — обновлённая тестовая версия

## Что добавлено
- Настоящий вызов модели `fal-ai/vidu/q4/image-to-video` через защищённые Netlify Functions.
- Сжатие фотографии в браузере перед отправкой.
- Проверка статуса задания и показ/скачивание готового MP4.
- Обязательное подтверждение перед платной генерацией.
- Защитный код для закрытого бета-тестирования, чтобы публичная ссылка не позволяла любому посетителю тратить средства владельца.
- API-ключ `FAL_KEY` используется только на сервере и не помещается в HTML.

## Переменные Netlify
В настройках проекта → Environment variables должны быть:

1. `FAL_KEY` — существующий секретный ключ fal.ai.
2. `TRENDVIDEO_ACCESS_CODE` — придуманный владельцем секретный код доступа для бета-тестирования. Не использовать пароль от Netlify или fal.ai.

Обе переменные должны быть доступны контексту Production и функциям (если выбор Scope доступен). После изменения переменных нужно выполнить новую публикацию.

## Публикация
Проект содержит `netlify.toml` и папку `netlify/functions`. Netlify должен собрать и опубликовать функции вместе с сайтом. Если ручная загрузка через Drop не опубликует функции, подключите эту папку проекта через Git-подключение Netlify или опубликуйте через Netlify CLI.

## Важно о расходах
Каждый успешный запуск модели платный. Сайт показывает ориентировочную стоимость и запрашивает подтверждение перед отправкой. Цены fal.ai могут изменяться; проверяйте актуальный тариф модели перед тестом. Не запускайте генерацию, пока не готовы оплатить её.

Модель: `fal-ai/vidu/q4/image-to-video`, разрешение 540p или 720p, длительность 5/8/10 секунд. Формат кадра зависит от исходной фотографии; отдельное принудительное изменение пропорций не включено.
